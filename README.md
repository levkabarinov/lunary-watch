# Lunary Watch

Адаптивный frontend-прототип сервиса совместного просмотра в фирменном стиле Lunary.

## Возможности прототипа
- Главная страница и демо-каталог.
- Создание комнаты и вход по коду (демо-интерфейс).
- Встраивание YouTube и прямых ссылок на видеофайлы.
- Чат в интерфейсе комнаты.
- Адаптивная мобильная версия.

## Ограничения
Комнаты пока не являются сетевыми: код не создаёт постоянную комнату на сервере, чат не синхронизируется между разными устройствами, а полноценная синхронизация YouTube требует backend и Realtime/WebSocket. Используйте только контент, который разрешено воспроизводить и встраивать.

## Запуск
Откройте `index.html` или опубликуйте репозиторий через GitHub Pages (Settings → Pages → Deploy from a branch → main → /root).
